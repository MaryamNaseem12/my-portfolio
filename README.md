# Maryam Naseem's Personal Portfolio

A sleek, modern, single-page application built to showcase my Software Engineering and AI projects. 

## Features
- **Dark Mode Aesthetic**: A premium dark theme with vibrant blue and cyan accents.
- **Glassmorphism Design**: Frosted glass effects on navigation and project cards.
- **Fully Responsive**: Optimized for both desktop and mobile viewing.
- **Performance**: Built with raw HTML, CSS, and Vanilla JS for maximum speed.

## Sections
1. **Hero**: Animated typing and call-to-action buttons.
2. **About Me**: A professional bio highlighting my background in CS and my current focus on Applied AI & Medical Data Pipelines.
3. **Projects**: Beautifully designed CSS cards linking to my top GitHub repositories.
4. **Contact**: Direct links to my email and GitHub.

## Local Setup
To run this portfolio locally, simply clone the repository and open `index.html` in your web browser. No server or build steps required.
